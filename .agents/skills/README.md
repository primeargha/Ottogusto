## Project Overview

**OttoGusto** is a multi-store e-commerce platform specializing in automotive parts and sustainable products. The platform supports:

- **Two distinct stores**: Ottogusto (automotive parts) and Qverde (sustainable products)
- **Multi-language support**: English, French, Dutch, German
- **Cross-platform architecture**: Next.js web app with React Native compatibility
- **Advanced search**: Vehicle fitment system with Make/Model/Engine filtering
- **Modern tech stack**: Next.js 14, TypeScript, Zustand, Gluestack UI, Tailwind CSS

## Key Technologies

### Frontend
